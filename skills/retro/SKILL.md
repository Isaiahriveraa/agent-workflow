# Retro

Review the current session unless the user names another. For another session, use the log or handoff they provide; ask for it if you cannot locate it. Do not search unrelated sessions.

1. Find a concrete moment that caused rework, repeated correction, or a missed check. Cite the turn, command, or artifact. Leave secrets out.
2. Check the instruction or tool that should have helped. Distinguish a missing rule from an existing rule that was loaded too late or was not enforced.
3. Propose at most one change. Name where it belongs and how to tell whether it helped next time. Prefer fixing an existing instruction or check over adding a new one. If the evidence does not justify a change, say so.

Keep this read-only. Wait for approval before editing the workflow.
