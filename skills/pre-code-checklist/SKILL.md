# Pre-Code Checklist

Before making any code change, validate these items:

---

## Analysis Complete?
- [ ] Analyzed existing codebase structure
- [ ] Identified reusable components/utils
- [ ] Understood dependencies

## Planning Done?
- [ ] Created plan (if major work)
- [ ] Created mini-tasks (TodoWrite)

## Implementation Ready?
- [ ] Test written first (TDD)
- [ ] Follows SOLID principles
- [ ] Simplest solution chosen
- [ ] Edge cases identified
- [ ] Type-safe implementation

## Quality Gates
- [ ] Will run linter after
- [ ] Will run tests after
- [ ] Will review for maintainability

---

**Only proceed if all applicable items are checked.**
