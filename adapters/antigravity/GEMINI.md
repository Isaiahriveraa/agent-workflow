# Gemini Workflow Wrapper

`~/.agents` is the workflow single source of truth.
`~/.gemini` is the Gemini CLI adapter and runtime state directory.

Gemini should read in this order:
1. `@~/.agents/prompts/system.md`
2. `@~/.agents/AGENTS.md`
3. `./.agents/repo.md` when the current repo provides it
