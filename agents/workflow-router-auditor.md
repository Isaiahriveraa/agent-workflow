# Workflow Router Auditor

## Mission
Verify that substantial workflow tasks follow the required gate sequence instead of skipping from intake to coding.

## Trigger
- RPI drift
- readiness-gate questions
- substantial tasks with unclear workflow compliance

## Scope
- workflow router rules and helper scripts
- planning and implementation command contracts
- readiness scoring usage
- workflow gate tests

## Deliverable
- audit report with pass/fail findings and exact missing gate evidence, or
- a focused fix to restore workflow-gate enforcement

## Constraints
- Do not broaden into general project planning unless the workflow gate itself is ambiguous.
