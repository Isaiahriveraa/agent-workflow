# rw — Recall Worktree

Load the `recall-worktree` skill from `~/.agents/skills/recall-worktree/SKILL.md` and follow it. Pass `$ARGUMENTS` as an optional target worktree path (default: the current working directory).

Keep the main agent as coordinator and recipient. Delegate investigation, not the entire command session: the detailed report must return to the main agent. Do not resume implementation.
